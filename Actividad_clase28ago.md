### 1. Aplicación tipo whatsapp que trabaje con lora

Se puede desarrollar con java teniendo en cuenta que es uno de los principales utilizados en whatsapp, podemos usar flutter en dado caso de que se quiera implementar en varios dispositivos, se puede implementar el patron llamado observer. Para implementar lora se podría usar c o c++.

### 2. Aplicación que permita contar espacios vacios en un estacionamiento

Python es el ideal ya que es muy usado en este tipo de proyectos debido a la cantidad de librerias que tiene. Se tienen que tener camaras en el estacionamiento (que tengan una resolución suficiente para evitar errores de conteo). Utilizar librerias de ia para el reconocimiento de los espacios disponibles y contarlos (yolo tal vez), cuidando que no marque como disponible cualquier parte donde no haya un automovil (una calle por ejemplo).
